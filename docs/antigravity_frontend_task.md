# Antigravity task: build a printable synthetic-case report

Work only in `frontend/` on a useful product feature for our **CardioRisk research demo**. The live React app calls `POST /api/predict` and receives `probability`, `percentage`, `outcome`, `horizon_years`, `model_id`, `calibrated`, `factors`, `missing_fields`, `outside_training_range`, and `notice`. The backend is being changed separately for a calibration experiment, so do not edit `backend/`, `scripts/`, `data/`, `models/`, `docs/model_*`, or `docs/calibration_*`. Preserve the existing form and response contract.

Add a **Print / Save as PDF** action to the assessment result. It should create a clean, one-page print layout using the browser's print function and the existing result data; no server endpoint, database, patient name, or identifier is needed. Include the exact outcome and 10-year horizon; the probability with its preliminary/calibration status derived from the API; model ID and US NHANES source population; top model factors with clear wording that they are model associations rather than causal effects; missing-input and outside-training-range warnings; and the prominent research-only, synthetic-example disclaimer. Do not add treatment advice, low/medium/high categories, confidence percentages, or claims of clinical validation.

Keep the normal screen layout intact and make the print layout readable on A4 or US Letter. The print action should be disabled or hidden before a result exists. Add a small frontend test only if it verifies a meaningful UI behavior; otherwise rely on `npm run build` and a browser check. Report exactly which files changed and how you tested it. Do not modify or restate the literature matrix.
