# Prespecified baseline model plan v1

**Date:** 6 October 2026. **Scope:** Public-data research prototype only. No hospital records or private ten-year outcomes are available. This plan is written before fitting the first model.

## Data and target

Use `data/processed/cohort_v1.csv` generated by `scripts/build_cohort.py`. The target is cardiovascular death within 120 months of the NHANES examination. Development cycles are 1999–2006; 2007–2008 is a temporal evaluation cycle. Do not use evaluation outcomes to choose variables, imputation, tuning, calibration, or thresholds.

The fixed eight inputs are age, NHANES recorded gender category, mean systolic BP, BMI, total cholesterol, HDL cholesterol, current smoking, and self-reported diabetes. Current values outside common ranges remain in the initial baseline and are flagged for a separate sensitivity analysis; no test-set-driven trimming.

## First model

Fit regularized logistic regression with the library default L2 strength (`C=1.0`), no class weighting, and a fixed random seed. Median-impute the five continuous fields (age, systolic BP, BMI, total cholesterol, HDL) within each training fold; standardize them after imputation. Most-frequent-impute the three categorical/binary fields (recorded gender, smoking, diabetes) within each training fold. Treat gender as a two-level category, not a numeric quantity. All preprocessing is fit inside the model pipeline to prevent leakage.

Use five stratified folds over development participants to obtain out-of-fold probabilities. Refit the same pipeline on all development participants and evaluate once on the 2007–2008 cycle. No hyperparameter search is planned for this first baseline.

## Reporting

- Report `n`, events, prevalence, AUROC, AUPRC, Brier score, calibration intercept and slope, and a calibration plot for out-of-fold development and held-out evaluation predictions.
- Use 95% person-level bootstrap intervals for AUROC, AUPRC, and Brier score as an initial precision check. These are sample-level intervals and do not account for the complex NHANES survey design; do not label them population intervals.
- Do not select a risk threshold or report clinical decision sensitivity/specificity until the intended action and threshold are justified.
- Report complete-case performance only as a later sensitivity analysis. The primary baseline uses fold-fitted imputation to retain all 274 development and 87 held-out events.
- Do not report age-by-gender subgroup performance as conclusive; the held-out cells have only 6–28 events.
- Keep model explanations and calibration adjustment for later prespecified experiments. SHAP is not a substitute for performance validation.

## Known limitations

The public-use mortality file contains privacy-protecting substitutions for some times and causes. NHANES is a US survey, and HDL measurement methods changed across cycles. The model is not validated for local clinical care or individual diagnosis. The eventual web demonstration will use synthetic examples.
